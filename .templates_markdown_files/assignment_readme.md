## Folder Structure

- **`input/`** — Stores the assignment instructions and any attachments or starter files provided with the task. Keep original reference files unmodified here.
- **`workspace/`** — The working area for drafts, LaTeX/Markdown sources, code, and experiments. Files here are expected to change and do not need to be in final submission format yet.
- **`assets/`** — Holds supporting attachments used by the workspace, report documents, or code, such as images, figures, diagrams, and plots.
- **`output/`** — Contains the final deliverables ready for hand-in, such as rendered `.pdf` reports and `.zip`/`.rar` source code archives (plus standalone images if explicitly required).
