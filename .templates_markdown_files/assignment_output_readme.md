# Output

This folder contains the final, submission-ready deliverables for the assignment.

## What to Expect Here

- Rendered `.pdf` documents compiled from LaTeX or Markdown files in `../workspace/`
- Compressed source code archives (`.zip` or `.rar`) when source code must also be handed in
- Standalone image files only if the assignment explicitly requires submitting images separately rather than embedded inside the report

In most cases, this folder should contain only `.pdf`, `.zip`, and `.rar` files ready for submission.
